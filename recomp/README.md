# recomp/ - the ReXGlue recompilation project (Milestone 3 skeleton)

Skeleton produced by `rexglue init` (ReXGlue SDK 0.10.0, run on Linux in session 1 against a synthetic XEX
header) and edited. It is **not buildable yet**: it needs the SDK (`REXSDK_DIR` pointing at a pinned checkout
of `rexglue/rexglue-sdk`, or an installed SDK package) and, for the codegen step, the player's own
TU3-patched `game/default.xex`, which is never committed.

| File | Purpose |
|---|---|
| `ttt2_manifest.toml` | what `rexglue codegen` recompiles (`game/default.xex`, local only) and which config it includes |
| `ttt2_config.toml` | codegen configuration: flags, invalid-instruction regions, later function boundaries, switch tables, hooks |
| `CMakeLists.txt`, `CMakePresets.json`, `generated/rexglue.cmake` | the SDK's project boilerplate (BSD-3; `rexglue.cmake` is regenerated by the SDK, do not edit) |
| `src/main.cpp`, `src/ttt2_app.{h,cpp}` | the host application (`rex::ReXApp` subclass) |
| `generated/default/` | codegen output: git-ignored and refused by the hygiene check |

Workflow once the inputs exist (Milestone 3):

```sh
# 1. produce game/default.xex locally (patched with Title Update 3; tooling in progress)
# 2. generate C++ from it
rexglue codegen ttt2_manifest.toml          # or: cmake --build ... --target ttt2_codegen
# 3. build the host with the generated code
cmake --preset linux-amd64-release -DREXSDK_DIR=/path/to/rexglue-sdk && cmake --build --preset linux-amd64-release
```

Validation without game files uses the SDK's own PowerPC instruction tests (`rexglue recompile-tests`) and the
programs in `tests/ppc/`, see `docs/DEVELOPMENT.md`.

| Path | Purpose |
|---|---|
| `tools/find_switch_tables.py` | symbolic switch-table finder; writes `[[switch_tables]]` for the config (required: the SDK's detector misses/miscompiles several shapes) |
| `tools/codegen_report.py` | summarises a codegen run as REPORT.md / JSON (counts, addresses, names only) |
| `tests/ppc/*.c`, `*.s` | license-free PowerPC test programs: smoke, jump-table shapes (`switch_ttt2.s`), the TTT2 instruction list (`insn_ttt2.s`) |
| `tests/host/` | headless host: runs a recompiled test program through the runtime and checks its results |
| `ttt2_instructions.txt` | the 66 instructions TTT2 needs beyond XenonRecomp's original set (from TTT2 Web, CC0) |
| `src/ttt2_app.cpp` | `Ttt2App` hooks: paths, executable identification, import summary, guest-thread watchdog |
